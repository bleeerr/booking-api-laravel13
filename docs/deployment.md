# Deployment notes

`compose.yaml` — локальная конфигурация, **не production-ready**: bind mount исходников, Xdebug в dev-образе, публикация HTTP только на `127.0.0.1:8080`, логирование почты вместо SMTP.

Для публичного развёртывания потребуются отдельная сборка без dev-зависимостей и Xdebug, TLS/reverse proxy, управление секретами, настроенный почтовый транспорт, резервное копирование PostgreSQL, мониторинг queue worker и безопасная настройка сетей/доступа к БД.

**Нельзя** переносить локальный `.env` с демонстрационными паролями на сервер. `APP_ENV=production`, `APP_DEBUG=false`, сохранение постоянного `APP_KEY` и миграции через `php artisan migrate --force` обязательны для соответствующего окружения.

`DatabaseSeeder` допускает демонстрационные данные только в `local` или `testing`. Для production используйте отдельный сценарий и не запускайте `migrate:fresh`.

Для обзора без развёртывания достаточно [OpenAPI](openapi.yaml) и [архитектуры](architecture.md).
